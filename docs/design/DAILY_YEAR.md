# หนึ่งปีแห่งสายน้ำ — แผนพัฒนารายวัน

สถานะ: ผู้ใช้ให้พัฒนาตามแนวทางในบทสนทนา 2026-11-03 เริ่มต้นแบบย่อยตามลำดับ ไม่ใช่การเปิดทุกระบบหรือการยืนยันสมดุล ดูขอบเขตที่มีจริงใน [คู่มือต้นแบบ](../features/DAILY_PRODUCTION.md) และ [STATUS](../STATUS.md)

## เป้าหมาย

หนึ่งรอบ 365 วัน: อ่านพยากรณ์ → จัดแรงงานและโครงการ → เดินเวลา → ผลผลิต/ภัย → ผ่านโจทย์ → เลือกพัฒนา → เตรียมโจทย์ที่ยากขึ้น เพิ่มการตัดสินใจและความก้าวหน้า แทนการให้ผู้เล่นกดจบวันซ้ำ ระยะต้นไม่ขยายรอบเดิมเป็น 1,825–3,650 เทิร์น

ปฏิทินสมมติ: แล้ง 1–120, ฝนเริ่มต้น 121–180, น้ำหลาก 181–300, น้ำลด 301–365 ค่าทั้งหมดต้องปรับหลังทดลอง มีจังหวะวางแผนรายวัน/สัปดาห์/ฤดู และเดินเวลาถึงเหตุการณ์พร้อมหยุดก่อนภัยที่ผู้เล่นยังแก้ได้

## ระบบเป้าหมาย

| ระบบ | แนวทาง |
|---|---|
| แรงงาน | คนหนึ่งทำงานหนึ่งอย่าง มอบหมายต่อเนื่อง พัก/เปลี่ยนงานได้ โครงการเก็บความคืบหน้า |
| การผลิต | เก็บวัตถุดิบ → โรงเลื่อย/เตาเผา → วัสดุ → บ้าน/บึง/ประตู; โรงช่างและชุดกลไกมาทีหลัง |
| ทรัพยากร | เริ่มอาหาร ไม้ หิน ดินเหนียว ไม้แปรรูป อิฐ; เพิ่มเส้นใยและชุดกลไกหลังพิสูจน์วงจรพื้นฐาน |
| อาคาร | ของจำเป็นอยู่รอดสร้างได้จากวัสดุพื้นฐาน อัปเกรดเพิ่มทางเลือกพร้อมต้นทุน คลังร่วมก่อนระบบขนส่ง |
| น้ำ | ปรับอัตรารายวัน ฝนสะสม หลายระลอก และพยากรณ์ ไม่ใช้ผลผลิต/ฝนต่อเทิร์นเดิมตรง ๆ |
| อาหาร | กินรายวัน HUD แสดงจำนวนวันที่พอ ปลาเป็นอาหารระหว่างรอข้าว เก็บเกี่ยวเป็นช่วง |
| ฟื้นตัว | ซ่อมถูกกว่าสร้างใหม่ เตือนก่อนอาหาร/บ้านขาด มีโจทย์ฟื้นฟูที่ไม่คุ้มให้จงใจทำภัย |
| ความก้าวหน้า | ความรู้จาก Challenge ใช้เลือกสายจัดการน้ำ/ชุมชนและเสบียง/ธรรมชาติ ผสมข้ามสายได้ |
| รางวัล | ประโยชน์ใช้ได้ในโจทย์ถัดไป มีทั้งเพิ่มประสิทธิภาพและเปิดวิธีแก้ใหม่ รางวัลเดิมไม่รับซ้ำ |
| แผนที่ | เป้าหมายรัศมี 6 = 127 ช่อง มีที่สูง/กลาง/ลุ่ม วัสดุพื้นฐานเข้าถึงได้ และหลายทางระบายน้ำ |
| ข้ามรอบ | เริ่มความสามารถใหม่ทุกครั้ง เก็บตรา/สถิติ/ภาพตกแต่งก่อนโบนัสพลังถาวร |

## ขั้นพัฒนาและเกณฑ์ผ่าน

| ขั้น | ผลงาน | เกณฑ์ก่อนขยาย |
|---|---|---|
| 1 เวลา | วัน งานต่อเนื่อง เดิน/หยุดเวลา | ข้ามวันตรงกับเดินทีละวัน หยุดเตือนได้ทัน |
| 2 ผลิต | โรงเลื่อย เตาเผา วัสดุและจัดคนในโจทย์สั้น | สายผลิตใช้ได้จริง ไม่ต้องสั่งซ้ำทุกวัน |
| 3 Reward | โจทย์ต่อกัน ความรู้และอัปเกรดชุดเล็ก | ผู้เล่นเข้าใจและใช้รางวัลในโจทย์ถัดไป |
| 4 ปีเต็ม | น้ำ อาหาร นา คลัง เติบโตและซ่อมครบ 365 วันบน 61 ช่อง | ไม่มีช่วงว่างยาวและยังฟื้นตัวได้ |
| 5 พื้นที่ | 127 ช่องและแหล่งวัสดุจริง | หลาย seed เล่นได้ พื้นที่เพิ่มสร้างแผนใหม่ |
| 6 ขั้นสูง | โรงช่าง ชุดกลไก สามสายพัฒนา | หลายกลยุทธ์สำเร็จ ไม่มีสายคุ้มที่สุดเสมอ |
| 7 สมดุล | UI บทสอน จังหวะภัยและรางวัล | คนเล่นเข้าใจเหตุแพ้ชนะและอยากลองแผนใหม่ |

ต้นแบบ 30 วันทำฐานขั้น 1–3 โดยใช้ภัยตามวันและรางวัลแบบเส้นตรง ยังไม่ผ่านเกณฑ์ทดลองโดยคน ไม่ใช่การทำขั้น 1–3 ครบทุกเป้าหมาย

## สถาปัตยกรรมและเงื่อนไข

- คงกฎเดิม/เซฟเดิม แยก controller/ruleset ของรายวัน ใช้กฎน้ำร่วมเมื่อผ่านการปรับสมดุลแล้ว
- แยก deterministic core, UI และ session I/O; preview/Undo/Redo/การอ่าน UI ไม่เปลี่ยนผลสุ่ม
- สูตร ต้นทุนและเวลาจัดไว้ในข้อมูลสมดุล เซฟต้องเก็บงานค้าง วัสดุสำรอง ความก้าวหน้าและรางวัลครบ
- ขั้นถัดไปก่อนรวมแผนที่: กำหนดสิทธิ์พื้นที่โรงงาน แหล่งวัตถุดิบ ปริมาณงานรายวัน และปฏิทินอาหาร แล้วทำ fixture เปรียบเทียบผล ไม่เร่งรวมระบบด้วยการแค่เพิ่มจำนวนเทิร์น

## หลักฐานที่ต้องเก็บ

เวลาตัดสินใจเทียบกับรอ, การใช้รางวัลหลังได้รับ, เหตุคิวติดขัด, การแพ้จากข้อมูลที่ไม่เห็น, ความหลากหลายแผนสำเร็จ และสิ่งที่อยากลองในรอบใหม่ Automated replay ยืนยันความถูกต้องได้ แต่ใช้แทน human playtest หรือความสนุกไม่ได้
