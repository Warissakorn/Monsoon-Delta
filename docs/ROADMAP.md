## M0 โครงโปรเจกต์
- project.godot (ชื่อ Monsoon Delta, renderer Compatibility เพื่อให้ export เป็นเว็บและมือถือได้)
- โฟลเดอร์ตาม CLAUDE.md และ .gitignore (.godot/, screenshots/)
- tests/run_tests.gd: หาไฟล์ tests/test_*.gd เอง รันทุกฟังก์ชัน test_* มี assert_eq / assert_true / assert_near สรุปผลและคืน exit code
- data/balance.json ใส่ตัวเลขทั้งหมดจาก GDD
- **เสร็จเมื่อ:** เทสต์ตัวอย่างผ่าน และเทสต์ที่ตั้งใจให้พังทำให้ exit code ไม่เป็น 0 (ถ้า class_name ไม่ถูกโหลดตอนรัน headless ให้ import โปรเจกต์ก่อน)
- **คุณตรวจ:** เปิดโปรเจกต์ใน Godot ได้โดยไม่มี error

## M1 แผนที่ (core เท่านั้น)
- core/hex.gd (เพื่อนบ้าน ระยะ วงแหวน แปลงเป็นพิกัดในฉาก), core/game_state.gd, core/map_gen.gd (ที่ราบลุ่มตาม GDD §2)
- **เสร็จเมื่อ:** เทสต์ผ่าน: 61 ช่อง, เพื่อนบ้านถูกต้อง, seed เดิมได้แผนที่เดิม, แม่น้ำต่อจากต้นน้ำถึงทะเล, ศาลาไม่อยู่บนแม่น้ำ, to_dict แล้ว from_dict ได้ state เดิม

## M2 ระบบน้ำ + ของเล่นชิ้นแรก
- core/water_sim.gd ตาม GDD §3
- หน้าจอทดลอง: กระดาน hex 3D แบบเรียบง่าย น้ำโปร่งแสง กล้องหมุนและซูมได้ / คลิกซ้ายขุด คลิกขวาถม (ไม่ใช้แรงงาน) / Space จำลอง 1 เทิร์นฝน (น้ำเข้า 4) / R สร้างแผนที่ใหม่ / ชี้ช่องเห็นข้อมูล
- ระบบถ่ายภาพหน้าจอตาม CLAUDE.md (รองรับ --seed=)
- **เสร็จเมื่อ:** เทสต์ผ่าน: มวลน้ำอนุรักษ์ (คลาดเคลื่อน ≤ 0.001), น้ำไม่ไหลขึ้นที่สูง, ประตูที่ปิดกั้นน้ำได้, รันซ้ำได้ผลเดิม และภาพหน้าจอเห็นกระดานกับน้ำชัดเจน
- **คุณตรวจ (จุดสำคัญที่สุดของโปรเจกต์):** เล่น 15 นาทีแล้วถามตัวเองว่า บังคับทางน้ำสนุกไหม คาดเดาได้ไหม ถ้ายังไม่ใช่ ให้ปรับกฎน้ำจนกว่าจะใช่ก่อนไปต่อ

## M3 กฎเกมครบ (core)
- ทรัพยากร ทุกคำสั่งใน §5 ลำดับเกม §6 คะแนน §7 พยากรณ์ undo และ preview
- tools/bot_sim.gd มีบอท 2 แบบ: "ทำนาอย่างเดียว ไม่ป้องกันน้ำ" และ "greedy ง่าย ๆ" พิมพ์สถิติ อัตราชนะ ปีที่แพ้ สาเหตุ และประชากรเฉลี่ย (200 เกมควรเสร็จในราว 5 นาที ถ้าช้าให้ลดจำนวนตัวเลือกที่บอทลอง)
- **เสร็จเมื่อ:** เทสต์ทุกคำสั่งทั้งกรณีทำได้และทำไม่ได้, preview ตรงกับผลจริง 100% ใน 100 seed / บอททำนาอย่างเดียวควรแพ้ก่อนจบปีที่ 5 เกือบทุกเกม (น้ำต้องเป็นภัยจริง) ส่วนบอท greedy ควรรอดได้บางเกม ถ้าไม่เป็นแบบนี้ให้เสนอการปรับตัวเลข

## M4 เล่นจบ 1 รอบได้
- HUD แถบคำสั่ง ไฮไลต์ช่องที่ทำได้ tooltip พรีวิว undo จบเทิร์น หน้าสรุปปี หน้าแพ้/ชนะ บันทึกอัตโนมัติ และเมนูหลักเบื้องต้น ตาม §12
- ระบบแปลภาษา (translations/strings.csv คอลัมน์ keys,en,th) ใช้ฟอนต์ไทยจาก assets/fonts ใน theme และตั้ง internationalization/locale/include_text_server_data = true เพื่อให้ตัดคำไทยได้ในเกมที่ export
- **เสร็จเมื่อ:** เทสต์ save/load ผ่าน และภาพหน้าจอ HUD แสดงภาษาไทยถูกต้อง ไม่มีสระลอยหรือกล่องสี่เหลี่ยม
- **คุณตรวจ:** เล่นจนจบ 5 ปีโดยไม่ติดบั๊ก แล้วให้เพื่อน 1–2 คนลองเล่น

## M5 Roguelite
- ก่อนเขียนโค้ด: เสนอการ์ด 30 ใบ เหตุการณ์ 15 แบบ และความยาก 10 ระดับ ให้ผู้ใช้อนุมัติ
- การ์ด ผู้ใหญ่บ้าน เหตุการณ์ แผนที่ 3 แบบ ระบบปลดล็อก ความยาก และท้าทายรายวัน ตาม §8–11
- **เสร็จเมื่อ:** เทสต์ผลของการ์ดทุกใบ, บอทรันครบทุกแผนที่และทุกความยากโดยไม่ crash, seed รายวันเดียวกันได้เกมเดียวกัน

## M6 ภาพ
- ทำตาม §13: shader น้ำ สิ่งก่อสร้าง ต้นไม้ ฝน แสงตามฤดู แอนิเมชันน้ำไหล และ tween ตอนขุด/ถม/สร้าง
- ถ่ายภาพหน้าจอตรวจเองทุกครั้งที่แก้
- **คุณตรวจ:** ส่งภาพหน้าจอพร้อมความเห็น เช่น "น้ำสีเข้มไป" "บ้านเล็กไป" แล้ววนปรับจนพอใจ

## M7 เสียง + ความรู้สึกตอนเล่น
- ระบบเสียง (bus: Music / SFX / Ambience) ตาม §14 ถ้ายังไม่มีไฟล์เสียงฝนให้สังเคราะห์จาก noise
- ลูกเล่น: จอสั่นเบา ๆ ตอนบ้านพัง ตัวเลข "+อาหาร" ลอยขึ้น ปุ่มมีเสียงและเด้งเมื่อกด
- หน้าตั้งค่า: ระดับเสียง ภาษา เต็มจอ
- **คุณตรวจ:** เล่นแล้วรู้สึกดีไหม

## M8 บทสอนเล่น
- สอนในปีแรกบนแผนที่ seed ตายตัว ทีละขั้น: ขุด → ทำนา → ดูพรีวิว → จบเทิร์น → รับมือฤดูฝน
- ตรวจคำแปลไทย/อังกฤษให้ครบทุกข้อความ
- **คุณตรวจ:** ให้คนที่ไม่เคยเห็นเกมลองเล่นโดยคุณห้ามอธิบาย แล้วจดจุดที่เขางง
