# 13 ภาษาและฟอนต์

## [I-01] ไฟล์แปล
- translations/strings.csv คอลัมน์: keys,en,th (UTF-8, ใส่ค่าที่มีจุลภาคไว้ใน "...")
- ให้ Godot import เป็นไฟล์ .translation แล้วลงทะเบียนใน project settings

## [I-02] รูปแบบ key
| prefix | ใช้กับ |
|---|---|
| ui.* | ปุ่มและป้าย |
| hud.* | แถบบนและแผงข้อมูล |
| cmd.<id>.name / cmd.<id>.desc | คำสั่ง |
| err.* | เหตุผลที่สั่งไม่ได้ (05) |
| card.<id>.name / card.<id>.desc | การ์ด |
| leader.<id>.name / leader.<id>.desc | ผู้ใหญ่บ้าน |
| map.<id>.name / map.<id>.desc | แผนที่ |
| diff.<n> | คำอธิบายความยากแต่ละระดับ |
| event.<id>.title / .desc / .choice<n> | เหตุการณ์ |
| building.<id> / feature.<id> / level.<n> / season.<id> | ชื่อสิ่งต่าง ๆ |
| preview.* / summary.* / gameover.* / unlock.* | ข้อความผล |
| tut.* | บทสอนเล่น |
| msg.* | ข้อความระบบ |

- ข้อความที่มีตัวเลขใช้ format string เช่น `tr("preview.houses_destroyed") % n` โดย en = "%d house(s) will collapse" / th = "บ้าน %d หลังจะพัง"

## [I-03] ฟอนต์
- assets/fonts/Kanit-Regular.ttf และ Kanit-SemiBold.ttf (OFL, ผู้ใช้ดาวน์โหลดมาใส่เอง)
- ถ้าไม่มีไฟล์ → ใช้ฟอนต์เริ่มต้นและ push_warning
- ระยะบรรทัด (line_spacing) +4 เพื่อไม่ให้สระบนและวรรณยุกต์ชนกัน
- ต้องตั้ง include_text_server_data = true เพื่อให้ตัดคำไทยได้ใน build ที่ export
- Label ที่มีข้อความยาวต้องใช้ autowrap_mode = AUTOWRAP_WORD_SMART

## [I-04] ข้อบังคับ
- ทุก key ที่โค้ดและ data อ้างถึงต้องมีทั้ง en และ th ที่ไม่ว่าง
- ทุก id ใน cards.json, events.json, leaders และ maps ต้องมี key ครบ
- เทสต์ test_i18n ต้องตรวจทั้งสองข้อนี้
