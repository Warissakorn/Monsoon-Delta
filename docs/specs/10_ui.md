# 10 UI/UX

## [U-01] ทั่วไป
- ฐาน 1920×1080 รองรับขั้นต่ำ 1280×720 ใช้ anchor/container ทั้งหมด ห้ามวางตำแหน่งด้วยพิกัดตายตัว
- Theme สร้างใน theme_builder.gd:
  - ฟอนต์ Kanit-Regular (เนื้อหา) และ Kanit-SemiBold (หัวข้อ)
  - ขนาดฟอนต์: เนื้อหา 20, ปุ่ม 20, หัวข้อ 28, ชื่อหน้า 44
  - สีจาก palette.json → ui_*
- ข้อความทุกตัวผ่าน tr() (13)
- ห้ามสื่อสถานะด้วยสีอย่างเดียว ต้องมีข้อความหรือสัญลักษณ์ประกอบเสมอ

## [U-02] Input Map
| action | ปุ่ม |
|---|---|
| cmd_dig … cmd_granary | 1 dig, 2 fill, 3 paddy, 4 house, 5 stilt_house, 6 raft_house, 7 gate, 8 reservoir, 9 fish_trap, 0 granary |
| cmd_chop / cmd_plant / cmd_wheel / cmd_demolish | C / P / B / X |
| cam_left / right / up / down | A / D / W / S และปุ่มลูกศร |
| cam_rot_left / cam_rot_right | Q / E |
| zoom_in / zoom_out | ล้อเมาส์ขึ้น / ลง |
| toggle_preview / toggle_numbers | Tab / V |
| undo | Ctrl+Z |
| end_turn | Enter, Space |
| cancel | Esc, คลิกขวา |

- **Esc:** ถ้ามีคำสั่งที่เลือกอยู่ = ยกเลิกคำสั่ง / ถ้าไม่มี = เปิดเมนูหยุดเกม
- **คลิกซ้ายที่ GATE โดยไม่ได้เลือกคำสั่ง** = toggle_gate

## [U-03] หน้าจอเล่นเกม
**แถบบน** (สูง 56, เต็มความกว้าง)
- ซ้าย: "ปี 2/5 · ฤดูฝน · เทิร์น 5/6"
- กลาง: แรงงาน 3/8 · อาหาร 12 · ไม้ 4 · ประชากร 8/10 (ประชากร/ที่อยู่)
- ขวา: "น้ำเข้าเทิร์นนี้ 4.2 · ฝนปีนี้ 10.0–15.0" ตามด้วยปุ่ม ☰ (เปิดเมนูหยุดเกม)
- ฤดูแล้งแสดง "น้ำเข้าเทิร์นนี้ 0.5"
- ค่าที่ยังไม่เปิดเผยแสดงเป็น "?"
- การ์ดที่มี: แสดงเป็นแถวชื่อย่อใต้แถบบน ชี้แล้วเห็นคำอธิบาย

**แถบคำสั่ง** (ล่าง สูง 104)
- ปุ่มเรียงตามลำดับ [U-02] (ซ่อนคำสั่งที่ยังไม่ปลดล็อก)
- แต่ละปุ่มแสดง: ชื่อ, ปุ่มลัด, ต้นทุน "แรง 2 · ไม้ 2" ตามฤดูปัจจุบัน
- ปุ่มเป็นสีเทาเมื่อทำไม่ได้ทุกช่อง (ฤดูผิด หรือแรงงาน/ไม้ไม่พอ) โดย tooltip บอกเหตุผล
- ด้านขวาสุด: ปุ่ม "↶ ย้อน" และปุ่มใหญ่ "จบเทิร์น ⏎"

**แผงขวา** (กว้าง 340)
- **TileInfo** (ช่องที่เมาส์ชี้): พิกัด, ความสูง, น้ำ "0.42 (ตื้น) → 0.71 (ท่วม)", ป่า/นา (ผลผลิตสะสม), สิ่งก่อสร้าง, คำเตือน
- **PreviewPanel:** รายการผลที่จะเกิดตอนจบเทิร์น เช่น "บ้าน 1 หลังจะพัง", "นา 2 แปลงจะตาย", "ศาลาจะจมน้ำ: แพ้!", "ไซดักปลา +2 อาหาร" ถ้าไม่มีอะไรเกิดแสดง "ปลอดภัย"

## [U-04] การเลือกคำสั่งและเป้าหมาย
1. กดปุ่มหรือปุ่มลัด → command_mode = id
2. ช่องที่ valid_targets ได้ ไฮไลต์เขียว ส่วนช่องที่ชี้แต่ทำไม่ได้ขึ้นกรอบแดงพร้อมเหตุผลใน TileInfo
3. คลิกซ้ายช่องที่ทำได้ → apply_command → อยู่ในโหมดเดิมต่อ (สั่งซ้ำได้เรื่อย ๆ)
4. **waterwheel:** คลิกแรกเลือกช่อง แล้วเพื่อนบ้านที่ใช้ได้ไฮไลต์ คลิกที่สองเลือกทิศ
5. ทุกครั้งที่ state เปลี่ยน → คำนวณ preview ใหม่และอัปเดต HUD ทั้งหมด

## [U-05] พรีวิว
- เปิดอยู่เป็นค่าเริ่มต้น กด Tab เพื่อสลับ
- **ผีน้ำ:** แสดงผิวน้ำหลังจบเทิร์นแบบโปร่งแสง เฉพาะช่องที่น้ำต่างจากตอนนี้มากกว่า 0.05
- **ป้ายลอย** (Label3D billboard) เหนือช่อง: "!" แดง = สิ่งก่อสร้างจะพัง / "✕" ส้ม = นาจะตาย / "+1" เขียว = นาได้ผล / "+n" ฟ้า = ไซดักปลาได้ผล
- กดจบเทิร์นเมื่อพรีวิวบอกว่าจะแพ้ → ขึ้นหน้าต่างยืนยัน
- ฤดูฝนที่ยังมีแรงงานเหลือ ≥ 2 → ขึ้นหน้าต่างยืนยันแบบมีตัวเลือก "ไม่ต้องถามอีก" (เก็บใน settings)

## [U-06] หน้าต่างซ้อน (หยุดการรับคำสั่งบนกระดานระหว่างเปิด)
- **การ์ด:** ไพ่ 3 ใบเรียงแนวนอน (360×480) แต่ละใบมีชื่อ คำอธิบาย และแถบสีตามหมวด (น้ำ/อาหาร/สิ่งก่อสร้าง/แรงงาน) คลิกเลือกได้เลยโดยไม่ต้องยืนยัน
- **เหตุการณ์:** ชื่อ คำอธิบาย และปุ่มตัวเลือก (ตัวเลือกที่ทำไม่ได้เป็นสีเทาพร้อมบอกเหตุผล)
- **สรุปปี:** แสดงทุกตัวเลขของ harvest_report เป็นบรรทัด ตามลำดับเดียวกับ [T-13] แล้วปุ่ม "ปีถัดไป"
- **จบเกม:** ผลแพ้/ชนะพร้อมสาเหตุ, คะแนนแยกส่วน, seed, รายการที่ปลดล็อกใหม่ และปุ่ม "เมนูหลัก" / "เล่นอีกครั้ง (seed ใหม่)"
- **หยุดเกม:** เล่นต่อ, ตั้งค่า, แสดง seed, กลับเมนูหลัก (เกมบันทึกอยู่แล้ว)

## [U-07] เมนูหลักและตั้งค่ารอบใหม่
- **เมนูหลัก:** เล่นต่อ (ซ่อนถ้าไม่มีเซฟ), เกมใหม่, ท้าทายรายวัน (แสดงคะแนนวันนี้), บทสอนเล่น, ตั้งค่า, เครดิต, ออก
  - ถ้ายังไม่เคยเล่นบทสอน (tutorial_done = false) ปุ่ม "เกมใหม่" จะถามว่าอยากเล่นบทสอนก่อนไหม
- **เกมใหม่:**
  - แผนที่ 3 ใบ (ใบที่ล็อกเป็นสีเทาพร้อมเงื่อนไขปลดล็อก)
  - ผู้ใหญ่บ้าน 4 คน (แบบเดียวกัน)
  - ความยาก 0..highest_unlocked พร้อมรายการผลสะสมของระดับที่เลือก
  - ช่อง seed และปุ่มเริ่ม
- **ตั้งค่า:** สไลเดอร์เสียง 4 ตัว, ภาษา, เต็มจอ, ปุ่มรีเซ็ตโปรไฟล์ (ยืนยัน 2 ชั้น)

## [U-08] กล้อง
- pivot เริ่มที่ (0, 0, 0), ระยะ 14 (ปรับได้ 8–22 ทีละ 1.5 ต่อสเต็ปล้อ), มุมก้ม −50°
- yaw เริ่ม 0 (มองไปทาง −z) แล้วหมุนทีละ 60° แบบ tween 0.25 วินาที
- เลื่อนด้วย WASD ความเร็ว 10 หน่วย/วินาที ตามทิศ yaw หรือลากเมาส์กลาง
- จำกัด pivot ให้ห่างจากจุดกำเนิดไม่เกิน 8 หน่วย

## [U-09] Picking
- แต่ละช่องมี StaticBody3D + CollisionShape3D (CylinderShape3D รัศมี 0.95) สูงเท่าตัวช่อง เก็บ coord ไว้ใน meta
- หาช่องที่ชี้ด้วย raycast จากกล้อง
