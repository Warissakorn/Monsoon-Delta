## คำบังคับ
- **ต้อง** = บังคับ / **ห้าม** = ห้ามเด็ดขาด / **ควร** = ทำถ้าไม่ขัดข้อบังคับ / **อาจ** = เลือกทำได้

## กฎตัวเลข [N-01]
- น้ำเป็น float; จำนวนอื่น (ความสูง อาหาร ไม้ แรงงาน ประชากร) เป็น int
- EPS = 1e-6 ใช้เปรียบเทียบ float ทุกครั้ง
- "ปัดลง" = floori() / "ปัดขึ้น" = ceili() / "ปัด" = roundi()
- ต้นทุนแรงงานและไม้ที่คำนวณจาก modifier: `maxi(0, roundi(ค่า))` เว้นแต่ไฟล์นั้นระบุอย่างอื่น
- แสดงค่าน้ำทศนิยม 2 ตำแหน่ง และค่าพยากรณ์ทศนิยม 1 ตำแหน่ง

## คำศัพท์
| ไทย | โค้ด | ความหมาย |
|---|---|---|
| ช่อง | Tile | ช่อง hex 1 ช่อง |
| ความสูง | elevation | int −3..4 |
| น้ำ | water | float ≥ 0 (ความลึก) |
