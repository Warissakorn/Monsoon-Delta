# 14 เทสต์และบอท

## [TS-01] ตัวรันเทสต์
- tests/run_tests.gd extends SceneTree
- หา tests/test_*.gd เรียงตามชื่อ แล้วสร้าง instance (extends TestCase)
- เรียกทุกเมธอดที่ชื่อขึ้นต้นด้วย test_ เรียงตามชื่อ
- อาร์กิวเมนต์ --filter=xxx: รันเฉพาะไฟล์ที่ชื่อมี xxx
- พิมพ์ "PASS file::test" หรือ "FAIL file::test: ข้อความ" ทีละบรรทัด แล้วสรุป "N passed, M failed"
- quit(0 ถ้าไม่มี fail ไม่งั้น 1)

## [TS-02] TestCase (tests/test_case.gd)
- assert_true(cond, msg), assert_eq(a, b, msg), assert_near(a, b, tol, msg)
- fail(msg): บันทึกว่าเทสต์ไม่ผ่านแต่ไม่หยุดการรันเทสต์อื่น

## [TS-03] TestMaps (tests/test_maps.gd)
- `small(radius: int, elevation: int) -> GameState`: แผนที่ hex รัศมีตามที่ระบุ ทุกช่องสูงเท่ากัน ไม่มีทะเล ต้นน้ำ ป่า หรือสิ่งก่อสร้าง ใช้ mod ค่าเริ่มต้น phase PLANNING ปี 1 เทิร์น 1 ประชากร 10 อาหาร 10 ไม้ 10 แรงงาน 10
- `set_tile(s, q, r, props: Dictionary)`: แก้ฟิลด์ใดก็ได้ของช่อง

## [TS-05] บอท
- ใช้แค่ API ของ GameFlow และ CommandRules ห้ามแตะ state ตรง
- rng ของบอทแยกต่างหาก: seed = derive_seed(seed, 9000)
- อาร์กิวเมนต์: --bot=farmer|greedy|random|all, --runs=200, --map=plains|valley|estuary|all, --difficulty=0, --seed-start=1
- **ทุกบอท:** เลือกการ์ดใบแรกที่เสนอ และตัวเลือกเหตุการณ์ใบแรกที่ใช้ได้
- **farmer:** ทุกเทิร์นแล้ง ทำนาบนช่องว่างที่ level 0 ใกล้แม่น้ำที่สุดก่อน จนแรงงานหมด ไม่ทำอย่างอื่น
- **random:** สุ่มคำสั่งที่ทำได้จนแรงงานหมด (ใช้ใน test_preview)
- **greedy:** ทำซ้ำจนกว่าจะไม่มีคำสั่งไหนดีขึ้น:
  - สุ่มคำสั่งที่ทำได้ 40 แบบ (จาก dig, fill, paddy, house, stilt_house, chop, plant, gate, toggle_gate, fish_trap, granary)
  - ประเมินแต่ละแบบด้วย preview แล้วเลือกคะแนนสูงสุด ถ้ามากกว่าคะแนนตอนไม่ทำอะไร
  - คะแนน = −1000 × แพ้ + 3 × capacity − 8 × สิ่งก่อสร้างที่พัง − 3 × นาที่ตาย + 2 × ผลผลิตนาสะสม + food + 0.5 × wood
- **ผลลัพธ์:**
  - พิมพ์ตาราง: บอท, แผนที่, จำนวนรอบ, อัตราชนะ, ปีเฉลี่ยที่ไปถึง, สาเหตุแพ้ (hall/pop), ประชากรเฉลี่ยตอนจบ, คะแนนเฉลี่ย
  - เขียน CSV ที่ bot_reports/<bot>_<map>_d<n>.csv (อยู่ใน .gitignore)
