# ฤดูน้ำหลาก (Monsoon Delta)

เกมวางแผนเทิร์นเบสแนว roguelite: บังคับทางน้ำบนแผนที่ hex ให้หมู่บ้านรอดฤดูน้ำหลาก 5 ปี

## เอกสาร
- สเปก (แหล่งความจริงเดียว): docs/specs/ เริ่มอ่านที่ @docs/specs/00_README.md
- ความคืบหน้าและการตัดสินใจ: @docs/PROGRESS.md
- แผนงาน: docs/ROADMAP.md (แต่ละ milestone บอกว่าต้องอ่านสเปกไฟล์ไหน ให้อ่านไฟล์เหล่านั้นทั้งไฟล์ก่อนเริ่มงาน)

## Tech
- Godot 4 (stable ล่าสุด), GDScript, ระบุ type ทุกตัวแปร พารามิเตอร์ และค่าที่คืน
- คำสั่งเรียก Godot บนเครื่องนี้: `godot` (ถ้าไม่ตรงให้แก้เป็น path จริง; Windows ใช้ไฟล์ `_console.exe`)
- ห้ามติดตั้ง addon หรือไลบรารีภายนอกโดยไม่ถามก่อน
- โค้ด ชื่อ คอมเมนต์ และ commit message เป็นภาษาอังกฤษ

## กฎเหล็ก
- ทำตามสเปกตามตัวอักษร ห้ามเพิ่มฟีเจอร์ ปรับตัวเลข หรือ "ปรับปรุง" กฎเอง
- สเปกกำกวม ขัดกันเอง หรือทำตามไม่ได้: หยุดแล้วถาม อย่าเดา
  - ข้อยกเว้น: รายละเอียดเล็กที่สเปกไม่ได้พูดถึง (เช่น ชื่อตัวแปรภายใน) ตัดสินใจเองได้ แต่ต้องบันทึกใน PROGRESS.md
- โค้ดที่ทำตามกฎที่มีรหัส ให้ใส่คอมเมนต์ `# spec: W-04` และเทสต์ของกฎนั้นต้องมีรหัสเดียวกันในชื่อหรือคอมเมนต์
- ผู้ใช้ขอเปลี่ยนดีไซน์: แก้ไฟล์ใน docs/specs/ ก่อน แล้วค่อยแก้โค้ดและเทสต์ให้ตรง
- สถาปัตยกรรมและขอบเขตของแต่ละโฟลเดอร์: ดู 01_architecture.md (ห้ามละเมิด)

## คำสั่งตรวจงาน
- import ครั้งแรกหรือหลังเพิ่ม class_name: `godot --headless --path . --import`
- เทสต์: `godot --headless --path . --script res://tests/run_tests.gd` (exit code ≠ 0 = มีเทสต์ไม่ผ่าน) เพิ่ม `-- --filter=water` เพื่อรันเฉพาะไฟล์
- บอท: `godot --headless --path . --script res://tools/bot_sim.gd -- --bot=all --runs=200`
- ภาพหน้าจอ: `godot --path . -- --scene=game --seed=1234 --screenshot=screenshots/latest.png` แล้วเปิดไฟล์ดูเอง

## วิธีทำงาน
- ทำเฉพาะ milestone ที่ถูกสั่ง งานที่ควรทำเพิ่มให้จดใน PROGRESS.md

- งานภาพ: ถ่ายภาพหน้าจอตรวจเองก่อนบอกว่าเสร็จ
