# วางแผนเสบียงก่อนเก็บเกี่ยว

ใช้ได้ในรอบหลัก 5/10 ปีทุกกติกา รวม `balanced_v1` และโรงเรียนสายน้ำ เปิดจากปุ่ม **เสบียง · F2** ด้านบนหรือเมนูหยุดเกม แถบบนแสดงอาหารในคลัง เทียบอาหารที่ประชากรต้องกินปลายปี และข้าวที่ยังรอเก็บ ทั้งสามยอดอ่านจากกติกาของรอบที่กำลังเล่น

โหมดรายวัน 30 วัน รอบ 365 วัน และขนส่งใช้ปฏิทิน/หน้าจอของตนเอง หน้านี้ไม่ได้เปลี่ยนระบบอาหารของโหมดเหล่านั้น

## อ่านแผน

- **ตอนนี้** แยกอาหารในคลังออกจากอาหารข้าวที่สะสมในนามีชีวิต รวมโบนัสข้าวตามกฎจริง ข้าวนี้ยังใช้เลี้ยงคนไม่ได้จนกว่าจะเก็บเกี่ยว
- **หลังเทิร์นนี้** ใช้พรีวิวน้ำและผลผลิตของเทิร์นปัจจุบัน ปลาเข้าในคลัง ส่วนนายังคงเป็นข้าวรอเก็บ ยอดขาดคิดโดยมีเงื่อนไขว่าข้าวชุดนี้รอดถึงเก็บเกี่ยว ไม่ใช่คำสัญญาว่าจะรอดหรือการพยากรณ์ทั้งปี
- **เทิร์น 6** เปลี่ยนหัวตารางเป็นก่อนกินมื้อเก็บเกี่ยว และแสดงผลจริงตามพรีวิว: อาหารที่กิน อาหารใช้กับการเกิด เน่าเสีย อาหารคงเหลือ คนย้ายเพราะหิว/บ้านไม่พอ และประชากรหลังเก็บเกี่ยว
- **ศาลาจะจมน้ำ** แสดงคำเตือนและขีดแทนตัวเลขเก็บเกี่ยวที่ไม่เกิดขึ้น ไม่ให้ผลผลิตหรือผลรางวัลบนสถานะจริง

ตัวอย่าง `balanced_v1` ระดับ 0 เริ่ม 6 คน ต้องกินคนละ 8 รวม 48 หน่วยเมื่อเก็บเกี่ยว แม้คลังมี 72 ก็ยังควรเตรียมแหล่งอาหารสำหรับปีถัดไป ตัวเลขในหน้าต่างใช้กฎปัจจุบัน ไม่ตรึงไว้ที่ 6/8/48 คำอธิบายยุ้งแสดงอัตราเน่าในรอบนั้น และแยกบทบาทรักษาอาหารออกจากการผลิต

## กลับไปแก้แผน

ปุ่มเลือกไซ ทำนา ขุดบึง และยุ้งฉางเปิดเครื่องมือบนกระดาน ยังไม่ใช้คนหรือไม้จนคลิกช่องจริง ปุ่มที่ใช้ไม่ได้จะปิดพร้อมต้นทุนและเหตุผลตามกฎคำสั่งเดิม เช่น ทำนาไม่ได้ในฤดูฝนหรือแรงงานไม่พอ ทำคำสั่งแล้วแผนเสบียงปรับตามสถานะใหม่ Undo/Redo ใช้งานตามปกติ

Esc, F2 หรือปุ่มกลับปิดหน้าต่าง ถ้าเปิดจาก Pause จะกลับ Pause การเลือกเครื่องมือพากลับกระดานโดยตรง เครื่องมือที่เลือกค้างไว้ก่อนเปิดหน้าต่างยังอยู่เมื่อกลับไปปรับแผน กั้นการกดรับซ้ำช่วงสั้น ๆ หลังปิดเพื่อไม่ให้คลิก/Enter รัวไปจบเทิร์นหรือเปิดหน้าซ้ำโดยไม่ตั้งใจ

เมื่ออยู่หน้าสรุปเก็บเกี่ยวหรือจบรอบ ปุ่มนี้ปิดและแถบวางแผนซ่อน เพื่อไม่บวกข้าวที่เก็บไปแล้วซ้ำ การดูแผนไม่สุ่มฝน ไม่เปลี่ยน RNG ไม่ใช้ทรัพยากร ไม่ให้รางวัล ไม่เขียนเซฟ และไม่เพิ่มรูปแบบเซฟใหม่

## การทำงานและตรวจซ้ำ

[FoodBudget](../../core/food_budget.gd) อ่านสถานะกับพรีวิวปัจจุบัน ใช้ `Harvest.paddy_food_by_tile` คิดข้าว และเรียก `Harvest.do_harvest` บนสำเนาเฉพาะเทิร์นสุดท้าย [GameScreen](../../ui/game_screen.gd) ใช้ผลชุดเดียวกันทั้งหน้าวางแผนและคำเตือนจบเทิร์น [FoodPlanPanel](../../ui/food_plan_panel.gd) แสดงผลที่แยกจากสถานะจริง ไม่จำลองน้ำหรือเปลี่ยนกฎเอง

```sh
scripts/test.sh --filter=food_plan
scripts/test.sh
python3 scripts/check_docs.py
git diff --check
```

ชุดเฉพาะส่วนตรวจราคาอาหาร legacy/balanced/กฎทดลองนา ฝนอนาคตที่ยังไม่เปิดเผย ข้าวตาย ศาลาท่วม ผลเก็บเกี่ยว/เป้าหมาย/เกิด/เน่า ต้นทุนกินเป็นศูนย์ การไม่บวกข้าวซ้ำหลังเก็บเกี่ยว การเปิดจาก Pause/โรงเรียน ความถูกต้องของเซฟ/RNG/Redo และการเลือกเครื่องมือก่อนใช้คำสั่งจริง

Native ใช้ [food plan probe](../../tools/food_plan_probe.gd) กับ XDG และเซฟแยก ต้องมีหน้าต่างเรนเดอร์:

```sh
mkdir -p work/food-plan-qa/th
XDG_DATA_HOME="$PWD/work/food-plan-qa/th/data" XDG_CONFIG_HOME="$PWD/work/food-plan-qa/th/config" XDG_CACHE_HOME="$PWD/work/food-plan-qa/th/cache" godot --path . --audio-driver Dummy --resolution 1280x720 --script res://tools/food_plan_probe.gd -- --lang=th --out-dir="$PWD/work/food-plan-qa/th"
```

เปลี่ยน `th` เป็น `en` ทั้ง paths และภาษาเพื่อตรวจอังกฤษ กรณีแรกใช้แผนที่จาก seed 42 ของ balanced_v1 แล้วปลูกนาผ่านเมาส์จริงพร้อม Undo/Redo ส่วนกรณีเก็บเกี่ยวและศาลาจมน้ำใช้กระดานที่จัดไว้ก่อนเริ่มกรณี โรงเรียนใช้กระดานบท 03 จริง ไม่มีการฉีด gameplay state ระหว่างกรณี ผลนี้ยืนยันการทำงาน UI ไม่ใช่ human playtest หรือหลักฐานความสนุก/สมดุลใหม่
