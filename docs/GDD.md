# GDD: ฤดูน้ำหลาก (Monsoon Delta)

ตัวเลขทุกตัวเป็นค่าตั้งต้นไว้จูน ค่าที่ใช้จริงอยู่ใน data/balance.json

## 1. ภาพรวม
- เกมวางแผนเทิร์นเบสแนว roguelite เล่นคนเดียว รอบละ 30–45 นาที (5 ปี × 6 เทิร์น)
- พาหมู่บ้านริมแม่น้ำให้รอด 5 ปี ด้วยการขุด/ถมดิน ทำนา สร้างบ้าน และบังคับทางน้ำ
- ศัตรูคือน้ำซึ่งไหลตามกฎตายตัว ผู้เล่นจึงเห็นพรีวิวผลของเทิร์นปัจจุบันได้แม่นยำ 100%
- ลง PC (เมาส์ + คีย์บอร์ด) ก่อน ออกแบบ UI ให้ปรับลงจอสัมผัสได้ภายหลัง รองรับภาษาไทยและอังกฤษ

## 2. แผนที่
- hex พิกัด axial (q, r) รัศมี 4 = 61 ช่อง ต้นน้ำอยู่ขอบบน ทะเลอยู่ขอบล่าง (ตามมุมกล้องเริ่มต้น)
- ข้อมูลแต่ละช่อง: elevation (int 0–4 ยกเว้นบึงรับน้ำติดลบได้ถึง −3), water (float ≥ 0), feature (none/forest/sapling/paddy), building (none/hall/house/stilt_house/raft_house/gate/granary/fish_trap/reservoir/waterwheel), is_source, is_sea
- ช่องทะเล: ขอบล่าง 5 ช่อง สูง 0 ถูกตั้ง water = sea_level (ปกติ 0) ทุก iteration จึงทำหน้าที่ระบายน้ำ
- ช่องต้นน้ำ: ขอบบน 1 ช่อง (หุบเขามี 2 ช่อง) เป็นจุดที่น้ำไหลเข้า
- "ช่องว่าง" = ไม่มี building, feature เป็น none และไม่ใช่ทะเลหรือต้นน้ำ

### สร้างแผนที่แบบที่ราบลุ่ม (ค่าเริ่มต้น)
1. ความสูงพื้นฐานลดจากบนลงล่าง: แถวบน 3–4 กลาง 2 ล่าง 1 บวก noise ±1 (จำกัดในช่วง 0–4)
2. แม่น้ำ: เดินสุ่มเอนลงล่างจากต้นน้ำถึงทะเล ช่องแม่น้ำครึ่งบนสูง 1 ครึ่งล่างสูง 0 มีน้ำเริ่มต้น 0.3
3. ป่า 8–12 ช่อง จับกลุ่มกันบนช่องที่สูง ≥ 2
4. ศาลากลางบ้านอยู่ช่องสูง 2 ห่างแม่น้ำ 2 ช่อง ไม่อยู่ขอบแผนที่ บ้าน 3 หลังอยู่ช่องติดศาลาที่สูง ≥ 2
5. ตรวจว่าแผนที่ไม่โหดเกินไป: จำลองปีที่ 1 แบบไม่ทำอะไรด้วยน้ำเข้าค่ากลาง ถ้าศาลาโดนน้ำระดับ ≥ 1 ให้สร้างใหม่ด้วย seed ย่อยถัดไป

### แผนที่อื่น (ปลดล็อกภายหลัง)
- หุบเขา: ขอบซ้าย/ขวาสูง 3–4 ลาดลงสู่แม่น้ำกลางแผนที่ ต้นน้ำ 2 ช่อง flow_rate 0.7
- ปากแม่น้ำ: ทะเลทั้งขอบล่างและขอบล่างซ้าย พื้นที่ส่วนใหญ่สูง 0–2 ฤดูฝนน้ำทะเลหนุน (sea_level 0.6)

## 3. ระบบน้ำ
- หน่วยเดียวกัน: ความสูง 1 ระดับ = น้ำ 1.0 และผิวน้ำ = elevation + water
- ตอนจบเทิร์นจำลอง 20 iteration แต่ละ iteration:
  1. เติมน้ำที่ต้นน้ำ = น้ำเข้าของเทิร์นนี้ ÷ 20 (แบ่งเท่ากันทุกต้นน้ำ)
  2. ทุกช่องที่มีน้ำ หาเพื่อนบ้านที่ผิวน้ำต่ำกว่า แล้วปล่อยน้ำ outflow = min(water, ผลรวมส่วนต่าง ÷ (จำนวนเพื่อนบ้านที่ต่ำกว่า + 1) × flow_rate) แบ่งตามสัดส่วนส่วนต่าง โดยคำนวณจากค่าก่อน iteration ทั้งหมดแล้วบวกพร้อมกัน (flow_rate = 0.5)
  3. ช่องทะเล: ตั้ง water = sea_level และบันทึกปริมาณน้ำที่ออก/เข้าทะเล
- ประตูน้ำที่ปิดอยู่: ไม่รับและไม่ปล่อยน้ำ
- หลังจำลอง: ป่าที่โตแล้วซับน้ำ min(water, 0.3) และในฤดูแล้งทุกช่องระเหย 0.25 (ไม่ต่ำกว่า 0)
- ฤดูแล้งมีน้ำเข้า 0.5 ต่อเทิร์น แม่น้ำจะได้ไม่แห้งสนิท
- มวลน้ำต้องอนุรักษ์: น้ำรวมที่เปลี่ยน = น้ำเข้า − ออกทะเล + เข้าจากทะเล − ซับ − ระเหย

| ระดับน้ำ | ชื่อ | water |
|---|---|---|
| 0 | แห้ง | < 0.1 |
| 1 | ตื้น | 0.1 ถึงต่ำกว่า 0.5 |
| 2 | ท่วม | 0.5 ถึงต่ำกว่า 1.0 |
| 3 | ลึก | ≥ 1.0 |

## 4. ทรัพยากรและประชากร
- แรงงาน = ประชากร รีเซ็ตทุกต้นเทิร์น ใช้ไม่หมดก็หายไป
- อาหารและไม้สะสมในคลัง
- ที่อยู่ = ความจุรวมของบ้านทุกหลัง (ศาลาไม่นับ) คนที่บ้านพังยังทำงานได้จนถึงเก็บเกี่ยว
- เริ่มเกม: ประชากร 6, อาหาร 6, ไม้ 2, ศาลา 1, บ้าน 3

## 6. ลำดับเกม
### ต้นปี
1. ป่าอ่อนโตเป็นป่า รีเซ็ตสถานะข้าวทุกแปลง
2. เลือกการ์ดภูมิปัญญา 1 จาก 3 ใบ (สุ่มจากกองที่ปลดล็อก ไม่ซ้ำใบที่มีแล้ว)
3. ตั้งแต่ปีที่ 2 มีโอกาส 50% เกิดเหตุการณ์สุ่ม 1 อย่าง
4. พยากรณ์: แสดงช่วงน้ำเข้ารวมของฤดูฝนตามตาราง ค่าจริงสุ่มในช่วงนั้น แล้วแบ่งเป็น 3 เทิร์นด้วยน้ำหนักสุ่ม 0.25–0.45 (normalize)

| ปี | น้ำเข้ารวมฤดูฝน |
|---|---|
| 1 | 8–12 |
| 2 | 10–15 |
| 3 | 12–18 |
| 4 | 15–22 |
| 5 (มหาอุทกภัย) | 22–30 |

### แต่ละเทิร์น (เทิร์น 1–3 ฤดูแล้ง, 4–6 ฤดูฝน)
1. แรงงาน = ประชากร ถ้าเป็นเทิร์นฝนให้เปิดเผยน้ำเข้าที่แน่นอนของเทิร์นนี้
2. ผู้เล่นสั่งงาน พรีวิวอัปเดตทุกครั้ง (พรีวิว = resolve_turn บนสำเนา state)
3. จบเทิร์น resolve_turn ตามลำดับ:
   1. จำลองน้ำ (§3)
   2. ความเสียหาย: สิ่งก่อสร้างที่น้ำถึงเกณฑ์พัง / ข้าวที่น้ำถึงระดับ 2 ตาย (ผลผลิตสะสมปีนี้เป็น 0 และไม่โตอีกจนปีหน้า)
   3. ศาลาโดนน้ำระดับ ≥ 2 → แพ้ทันที
   4. ผลผลิต: เทิร์นฝน นาที่ยังไม่ตายและน้ำระดับ 1 สะสม +1 / เทิร์นแล้ง นาที่ติดบึงรับน้ำซึ่งมีน้ำ ≥ 0.5 สะสม +1 และดึงน้ำจากบึง 0.25 (นาปรัง) / ไซดักปลาตาม §5
4. จบเทิร์น 6 แล้วเข้าสู่การเก็บเกี่ยว

### เก็บเกี่ยว (สิ้นปี)
1. อาหาร += ผลผลิตสะสมของนาทุกแปลง
2. กิน: คนละ 1 ถ้าไม่พอ คนย้ายออกเท่าจำนวนที่ขาด และอาหารเหลือ 0
3. คนที่เกินที่อยู่ย้ายออก
4. คนเพิ่ม: อาหารที่เหลือทุก 2 หน่วย = +1 คน (ใช้อาหารนั้นไป) ไม่เกินที่อยู่ที่ว่าง
5. ถ้าไม่มียุ้งฉาง อาหารที่เหลือเน่าไปครึ่งหนึ่ง (ปัดลง)
6. ประชากรเหลือ 0 → แพ้ / จบปีที่ 5 → ชนะ
7. แสดงหน้าสรุปปี

## 7. คะแนน
คะแนน = (ประชากร × 10 + อาหาร + โบนัส) × (1 + 0.1 × ระดับความยาก)
โบนัส: ไม่เสียบ้านเลยทั้งเกม +50 / ศาลาไม่เคยโดนน้ำระดับ 1 ขึ้นไป +30

## 10. เหตุการณ์สุ่ม (ตัวอย่าง 8 แบบ ต้องมีครบ 15 แบบใน data/events.json)
- พ่อค้าเรือ: เลือกแลกไม้ 3 → อาหาร 4 หรืออาหาร 4 → ไม้ 3 หรือไม่แลก
- ปลาชุม: ปีนี้ไซดักปลาได้ผล 2 เท่า
- แล้งยาว: น้ำเข้าฤดูฝนปีนี้ −30% แต่ระเหย 2 เท่า
- พายุเข้า: น้ำเข้าเทิร์นฝนสุดท้าย +50% (แสดงในพยากรณ์)
- ผู้อพยพ: เลือกรับ 2 คน (ถ้าไม่มีที่อยู่จะย้ายออกตอนเก็บเกี่ยว) หรือปฏิเสธ
- หนูนา: ถ้าไม่มียุ้งฉาง อาหารในคลัง −25%
- ไฟป่า: ป่าสุ่ม 2 ช่องหายไป
- ฟ้าฝนเป็นใจ: ช่วงพยากรณ์ปีนี้แคบลงครึ่งหนึ่ง

## 11. ความต่อเนื่องข้ามรอบ
- ปลดล็อกเพิ่มทางเลือกเท่านั้น ไม่เพิ่มพลัง บันทึกที่ user://profile.json
- แผนที่: ที่ราบลุ่ม (มีตั้งแต่แรก) → หุบเขา (ชนะครั้งแรก) → ปากแม่น้ำ (ชนะในหุบเขา)
- ความยากระดับ 0–10 ปลดล็อกเมื่อชนะระดับก่อนหน้า แต่ละระดับเพิ่มข้อจำกัด 1 ข้อแบบสะสม เช่น น้ำเข้า +10% หรืออาหารเริ่มต้น −2
- ท้าทายรายวัน: seed = วันที่ (YYYYMMDD) แผนที่และผู้ใหญ่บ้านกำหนดจาก seed

## 12. UI/UX
- เมนูหลัก: เกมใหม่ (เลือกแผนที่ ผู้ใหญ่บ้าน ความยาก seed), ท้าทายรายวัน, เล่นต่อ, ตั้งค่า, ออก
- แถบบน: ปี/ฤดู/เทิร์น, แรงงานที่เหลือ/ทั้งหมด, อาหาร, ไม้, ประชากร/ที่อยู่, พยากรณ์
- แถบคำสั่งด้านล่าง: ปุ่มแสดงต้นทุน ปุ่มลัด 1–9 เลือกคำสั่งแล้วช่องที่ทำได้จะไฮไลต์ คลิกขวาหรือ Esc เพื่อยกเลิก
- ชี้ช่องแล้วเห็น: ความสูง น้ำ ระดับน้ำตอนนี้ → หลังจบเทิร์น และสิ่งก่อสร้าง
- พรีวิว (Tab สลับเปิดปิด): น้ำโปร่งแสงตามผลหลังจบเทิร์น ไอคอนเตือนบนสิ่งที่จะพังหรือตาย และข้อความสรุป เช่น "บ้าน 1 หลังจะพัง ข้าว 2 แปลงจะตาย"
- Ctrl+Z ย้อน / Enter หรือ Space จบเทิร์น (ถามยืนยันถ้าพรีวิวบอกว่าจะแพ้)
- กล้อง: Q/E หมุนทีละ 60° ล้อเมาส์ซูม WASD หรือลากเมาส์กลางเพื่อเลื่อน
- กด V แสดงตัวเลขระดับน้ำทุกช่อง สถานะสำคัญต้องมีไอคอนกำกับ ไม่ใช้สีอย่างเดียว
- บันทึกอัตโนมัติทุกต้นเทิร์นที่ user://save.json

## 13. ภาพ
- low-poly สร้างจากโค้ดทั้งหมด: ช่อง = CylinderMesh 6 ด้าน สูงระดับละ 0.4 หน่วย / ป่า = กรวย 2–3 ต้น / บ้าน = กล่อง + หลังคาจั่ว / เรือนใต้ถุนสูง = บ้านบนเสา 4 ต้น / ศาลา = หลังคาซ้อน 2 ชั้น / นาข้าว = ผิวเขียวอ่อนมีลายเป็นแถว
- น้ำ: แผ่น hex ต่อช่องที่ระดับผิวน้ำ shader ไล่สีตามความลึก (ตื้นฟ้าใส → ลึกน้ำเงินเข้ม) มีคลื่นเบา ๆ และฟองตามขอบ
- ตอนจบเทิร์นเล่นแอนิเมชันน้ำไหลราว 1.5 วินาที (เก็บ snapshot ระหว่าง iteration แล้ว interpolate)
- ฤดูแล้งแสงอุ่น ท้องฟ้าใส / ฤดูฝนท้องฟ้าเทาฟ้า มีฝนตก (particles)
- สีทั้งหมดอยู่ใน data/palette.json โทนหลัก: เขียวนา น้ำตาลดิน ฟ้าน้ำ
