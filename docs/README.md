## สิ่งที่ยังขาดและข้อควรตรวจ

- ไม่พบไฟล์ `03_hex_map.md` ในไฟล์แนบ แม้มีระบุในสารบัญต้นฉบับ ข้อมูลแผนที่ใน GDD ยังไม่ใช่สเปกไฟล์ที่ขาด
- ไม่ได้รับเอกสารเต็ม `15tech` มีเพียงตัวอย่างแยก 34 ไฟล์ที่ใช้ชื่อนี้ จัดไว้ใน `examples/` และเชื่อมโยงในดัชนีเทคนิค
- โค้ดต้นแบบ M0–M2 และผลตรวจอยู่ใน [PROGRESS](PROGRESS.md); สเปกแผนที่ 03 ยังขาด และ M2 ยังรอผู้เล่นทดลอง
- บางตัวอย่างระบุ Godot `4.7.2` และเกม `0.3.0` ขณะที่ตัวอย่าง project settings ระบุ `0.1.0` คงค่าต้นฉบับไว้ ต้องตรวจเวอร์ชันที่ใช้งานจริงก่อนนำไปใช้
- ตัวอย่างมีทั้งโค้ดบางส่วนและ placeholder จึงไม่ถือว่าเป็น implementation ที่พร้อมรัน

## การตรวจสอบต้นฉบับ
