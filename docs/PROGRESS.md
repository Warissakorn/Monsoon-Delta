- ต่อยอดพรีวิวเก็บเกี่ยวใน main ให้แสดงอาหารที่มี/ต้องใช้/กินจริงและความจุบ้าน โดยรักษารายงานเดิมครบทุกค่า ใช้สำเนาหลังน้ำ ไม่เปลี่ยนกฎเทิร์น RNG หรือเซฟ
- ระบุประตูเปิด–ปิด นาตาย/กำลังจะตาย และช่องรับน้ำของระหัดเป็นข้อความ แก้การแสดงผลผลิตสะสมของนาที่ตาย
- ปุ่มในหน้าต่างซ้อนรับโฟกัสและใช้ Tab/Shift+Tab/Enter/Space ได้ ยืนยันเริ่มที่ยกเลิก ป้องกันกด Enter ค้างแล้วข้ามสรุป และคืนวงชี้ช่องเมื่อปิดหน้าต่าง
- ปุ่มลัดไม่เลือกเครื่องมือที่ถูกปิด และแจ้งเหตุผลเมื่อคำสั่งเดิมใช้แรงงาน/ไม้ต่อไม่ได้
- native input ตรวจโฟกัส/Tab/Space/Enter และการกดค้างผ่าน พรีวิวอาหาร 8/กิน 6/เหลือ 1 ของ seed 42 ตรงกับเก็บเกี่ยวจริง พร้อม [ภาพพรีวิว](images/m4-harvest-forecast-th.png)
- เทสต์เพิ่ม 7 รายการและชุดรวม **176 รายการผ่าน** หลังรวม main ล่าสุด รวมเทสต์เก็บเกี่ยวเดิม ตรวจ projection เทียบผลจริง การคง state/RNG/undo/เซฟ และข้อความ/โฟกัสของ UI
- เป็นการต่อยอดหน้าจอ M4 ยังไม่เปลี่ยนค่า balance หรือเริ่มระบบการ์ด/เหตุการณ์ M5

- GameSession บันทึกหลังคำสั่ง/undo/เปลี่ยนเทิร์น/ผ่านสรุปปี โหลดกลับตรงเดิม; เซฟล้มเหลวแสดงข้อความและให้ลองใหม่ก่อนออก ไม่เพิ่ม I/O ใน GameFlow หรือ sandbox
- แปลข้อความจาก CSV พร้อม imported resources, จำภาษา/คำเตือนแรงงาน และเพิ่มโมเดลนา ประตู ยุ้ง ปลา บึง ระหัด

- ชุดทดสอบรวม 167 รายการผ่าน; native input ผ่านหนึ่งปีและโหลด HARVEST กลับตรงเดิม ตรวจภาษาไทย 1280×720/อังกฤษ 1600×900 พร้อม [ภาพ HUD](images/m4-game-th.png) และ [ภาพเก็บเกี่ยว](images/m4-harvest-th.png)
- ยังไม่ผ่านสมดุล M3 ครบและยังรอการเล่นตรวจโดยคน การ์ด/เหตุการณ์/โปรไฟล์และแผนที่อื่นยังไม่เปิดใช้งาน

## 2026-10-16 — ต้นแบบทดลองน้ำ M0–M2

เพิ่มโปรเจกต์ Godot 4.6.3 Standard ที่เปิดเล่นได้ด้วย Compatibility renderer และ `ui/boot.tscn`

- **M0:** ตั้งค่าโปรเจกต์ ข้อมูล balance/palette ตัวรันเทสต์อัตโนมัติ assertion แบบไม่หยุดเทสต์อื่น `--filter` และ CI
- **M1 (ตาม GDD; สเปก 03 ยังขาด):** แผนที่ที่ราบลุ่ม 61 ช่อง คณิตศาสตร์ hex, seed, Tile/GameState, deep copy, JSON roundtrip และคงสถานะ RNG
- **M2:** จำลองน้ำแบบ simultaneous delta ตาม W-03–W-09 ประตู ระหัด การซับและการระเหย หน้าทดลอง 3D ขุด–ถมไม่จำกัดแรงงาน กล้อง ข้อมูลช่อง ตัวเลขน้ำ seed/reset และถ่ายภาพหน้าจอ
- UI มีภาษาไทย/อังกฤษด้วย `--lang` และฟอนต์ Noto Sans Thai (OFL) ระบบแปล CSV ครบเกมตาม M4 ยังไม่ทำ
- ค่าของเกมอยู่ใน `data/balance.json` โดยเริ่มจากตัวอย่างเดิม เพิ่ม `map_generation` และ `sandbox`; สีอยู่ใน `data/palette.json`

### ผลตรวจ

ทดสอบด้วย Godot **4.6.3.stable**:

- เทสต์หลัก 32 รายการผ่าน ครอบคลุมโครงสร้างแผนที่และการสร้างซ้ำ seed 1–50, ศาลาปลอดภัยตลอดปีแรกด้วยน้ำค่ากลาง, และน้ำ 100 seed × 6 เทิร์นพร้อมเทียบผลซ้ำและมวลน้ำ (คลาดเคลื่อน ≤ 0.001)
- ทดสอบตัวรันด้วย fixture ชั่วคราว: assertion ที่จงใจผิด, runtime error, parse error และ constructor error ทำให้ exit 1 โดยเทสต์ถัดไปยังรัน; filter ที่ไม่ตรงกับเทสต์ทำให้ exit 1
- import และเปิด main scene แบบ headless โดยไม่มี script error
- ตรวจภาพจริงด้วย OpenGL Compatibility บน virtual display: กระดาน น้ำ ภาษาไทย และแผงข้อมูลอ่านได้ รวมถึงหลังจำลองฝน 3 ครั้ง
- integration probe ตรวจคลิกขุด/ถม, ปุ่ม Space, reset เดิม, เปลี่ยน seed, การเลือก 61 ช่องด้วย ray และ view refresh ไม่เปลี่ยน state

### สมมติฐานระหว่างรอสเปก 03

ใช้เฉพาะที่ราบลุ่ม; ยังไม่อ้างว่าตรง H-02/H-03/MG-05 ฉบับเต็ม:

- axial pointy-top; ทิศเรียง `(1,0), (1,-1), (0,-1), (-1,0), (-1,1), (0,1)`
- index เรียง q ก่อน r; world x = √3(q + r/2), z = 1.5r; y = elevation × 0.4
- ต้นน้ำ `(0,-4)` ทะเล 5 ช่องที่ r = 4; แม่น้ำเดินลงทีละแถวด้วยทิศ 4 หรือ 5
- ศาลาอยู่ภายใน สูง 2 ระยะใกล้สุดจากแม่น้ำเท่ากับ 2 และมีบ้านติดกัน 3 หลังบนพื้นที่สูง ≥ 2
- ป่า 8–12 ช่องเลือกให้เกาะกลุ่มบนพื้นที่สูง ≥ 2
- ตรวจความปลอดภัยโดยจำลองฤดูแล้ง 3 เทิร์นและฝน 3 เทิร์น น้ำฝนรวมเป็นค่ากลางปีแรก แบ่งเท่ากัน; ถ้าศาลามีน้ำระดับ ≥ 1 จะลอง seed ย่อยถัดไป สูงสุดตาม config โดยคง seed หลักเดิม
- JSON ของ dictionary ที่ไม่กำหนดชนิด (`stats`, `year_mods`, `harvest_report`) แปลงตัวเลขที่ไม่มีเศษเป็น int ทั้งตอนเขียนและอ่าน เพื่อให้เทียบ dict หลัง JSON roundtrip ได้; scalar float ของ state/tile คงชนิด float
