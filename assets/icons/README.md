# Interface icons

These 33 SVG assets were authored for Monsoon Delta. They depict build commands,
resources, water, seasons, goals, settlement conditions, map warnings and the
next-turn action; marker_plate.svg supplies a dark circular map backplate. They
use the game's warm paper color and inherit button state tinting from the theme.

The icons load locally through Godot's SVG importer; no remote asset service is
required.
