# ฤดูน้ำหลาก (Monsoon Delta)

เกมวางแผนเทิร์นเบสแนว roguelite สำหรับผู้เล่นคนเดียว: บังคับทางน้ำบนแผนที่ hex ให้หมู่บ้านรอดฤดูน้ำหลาก 5 ปี ออกแบบสำหรับ Godot 4 และ GDScript

Repo นี้เก็บเอกสารออกแบบและตัวอย่างประกอบจากไฟล์แนบ 54 ไฟล์ ปัจจุบันยังไม่มีโปรเจกต์เกมที่เปิดเล่นหรือรันเทสต์ได้

## ขอบเขตเอกสาร

สเปกรายหัวข้ออยู่ใน `docs/specs/` ส่วน GDD เก็บภาพรวมเดิมไว้ประกอบการอ่าน ตามข้อความในสเปก 00 ให้ยึดสเปกเฉพาะเรื่องเมื่อขัดกับเนื้อหาทั่วไป

ยังไม่ได้รับ `03_hex_map.md` และเอกสารเต็ม `15tech` จึงยังไม่ควรถือว่าสเปกครบถ้วน รายละเอียดอยู่ในสารบัญเอกสาร

ตัวอย่างโค้ด สคริปต์ CI และการตั้งค่า Claude Code อยู่ใน `docs/examples/` และ `docs/reference/` เพื่อใช้อ่านประกอบ ยังไม่ได้เปิดใช้งาน hooks, permissions หรือ workflow และไม่ได้รันสคริปต์จากไฟล์แนบ
