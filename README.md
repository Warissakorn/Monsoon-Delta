# ฤดูน้ำหลาก (Monsoon Delta)

เกมวางแผนเทิร์นเบสแนว roguelite สำหรับผู้เล่นคนเดียว: บังคับทางน้ำบนแผนที่ hex ให้หมู่บ้านรอดฤดูน้ำหลาก 5 ปี พัฒนาด้วย Godot 4 และ GDScript

ตอนนี้เปิดเล่น **รอบเกมที่ราบลุ่ม 5 ปี** ได้ผ่านเมนูหลัก: ใช้แรงงาน/ไม้สร้างหมู่บ้าน ดูพรีวิวน้ำ ย้อนคำสั่ง จบเทิร์น และเก็บเกี่ยว พร้อมบันทึกอัตโนมัติและ Continue ห้องทดลองน้ำ M2 ยังเปิดแยกได้ สมดุลเกมยังอยู่ระหว่างปรับ และการ์ด/เหตุการณ์ยังไม่เปิดใช้งาน

## เปิดเล่น

ใช้ **Godot 4.6.3** รุ่น Standard (ไม่ต้องใช้ .NET) ซึ่งเป็นเวอร์ชันที่ทดสอบแล้ว เปิด `project.godot` แล้วกด **F6 ที่ ui/boot.tscn** หรือ **F5** เพื่อเข้าเมนู เลือกเกมใหม่ ผู้นำ และ seed แล้วเริ่มเล่น

```sh
godot --path . -- --scene=menu --lang=th
# เริ่มรอบใหม่จาก command line (เขียนเซฟรอบปกติ):
godot --path . -- --scene=game --seed=42 --lang=th
```

คลิกปุ่มคำสั่งหรือใช้ปุ่ม 1–0, C, P, B, X แล้วเลือกช่องสีเขียว; Ctrl+Z ย้อน, Tab สลับพรีวิว, Space/Enter จบเทิร์น และ Esc ยกเลิกคำสั่ง/เปิดเมนูหยุดเกม คลิกประตูน้ำโดยไม่เลือกคำสั่งเพื่อเปิด–ปิด กลับเมนูแล้วเลือก Continue เพื่อเล่นต่อจากเซฟล่าสุด พรีวิวเทิร์นสุดท้ายของปีจะแสดงผลเก็บเกี่ยวและอาหาร/ประชากรคงเหลือก่อนตัดสินใจจบเทิร์น

เริ่มต้นที่ภาษา OS (ไทยหรืออังกฤษ) เปลี่ยนและบันทึกภาษาได้จากเมนู ใช้ `--lang=th`/`--lang=en` เพื่อกำหนดภาษาขณะเปิด ดู [ขอบเขตหน้าจอเกมและการตรวจ](docs/M4_PLAYABLE.md)

## ห้องทดลองน้ำ

เลือกจากเมนูหรือเปิดตรงได้:

```sh
godot --path . -- --scene=sandbox --seed=42 --lang=th
```

seed ใช้ได้ทั้งตัวเลขและข้อความ เช่น `--seed=monsoon` แผนที่และผลน้ำจะเหมือนเดิมเมื่อใช้ seed และคำสั่งชุดเดิม

| การควบคุม | ผล |
|---|---|
| คลิกซ้าย | ใช้เครื่องมือที่เลือก (เริ่มด้วยขุด) |
| คลิกขวา | ถมดิน |
| 1 / 2 | เลือกขุด / ถม |
| Space / Enter | จำลองฤดูฝน 1 ครั้ง เติมน้ำ 4.00 ที่ต้นน้ำ |
| R | แผนที่ seed ถัดไป |
| ปุ่มเริ่ม seed เดิม | คืนแผนที่และน้ำเริ่มต้น |
| Q / E | หมุนกล้อง 60 องศา |
| ล้อเมาส์ | ซูม (บริเวณแผงข้อมูลใช้เลื่อนแผง) |
| W A S D | เลื่อนกล้อง |
| V | แสดงตัวเลขความสูงและน้ำ |
| Esc / ปุ่มเมนูหลัก | กลับเมนู |

ชี้ช่องเพื่อดูข้อมูล ต้นน้ำ ทะเล ป่า และสิ่งก่อสร้างได้รับการป้องกันจากเครื่องมือ ขุด–ถมได้โดยไม่ใช้ทรัพยากรในช่วงความสูง −3 ถึง 4 โหมดนี้ยังไม่มีความเสียหาย การเก็บเกี่ยว หรือการแพ้ชนะ

## ระบบกฎเกม M3

เพิ่มคำสั่ง 15 แบบพร้อมต้นทุนแรงงาน/ไม้ ความเสียหายจากน้ำ การผลิต การเก็บเกี่ยว ประชากร พยากรณ์ คะแนน undo และพรีวิว ระบบนี้ใช้แผนที่ที่ราบลุ่ม โดยการ์ดและเหตุการณ์อยู่ใน M5

หลัง import โปรเจกต์หรือรันเทสต์แล้ว ใช้บอทตรวจเกมหลักได้:

```sh
godot --headless --path . --script res://tools/bot_sim.gd -- --bot=all --runs=20 --seed-start=1
```

`--bot=farmer` ทำนาอย่างเดียว, `--bot=greedy` เลือกคำสั่งจากพรีวิว, `--bot=random` ใช้ตรวจความคงที่ ผลแต่ละรอบบันทึก CSV ใน `bot_reports/` ใช้ `--runs=200` สำหรับ benchmark และ `--candidates=40` เพื่อเพิ่มจำนวนตัวเลือกของ greedy (ค่าเริ่มต้น 8 เพื่อจำกัดเวลาประเมิน)

ดู [API ขอบเขต M3 และผลตรวจสมดุล](docs/M3_CORE.md) ค่าเริ่มต้นของเกมยังต้องจูนให้บอททำนาอย่างเดียวแพ้ตามเป้าหมายก่อนถือว่า M3 ผ่านทุกเกณฑ์

ระบบ [บันทึก–โหลดรอบเล่น](docs/SAVE_IO.md) ตรวจไฟล์เสียและรักษาค่าจำลอง/RNG เชื่อมกับ Continue และ autosave หลังคำสั่ง/undo/จบเทิร์น/เก็บเกี่ยวแล้ว sandbox และบอทไม่เขียนเซฟรอบปกติ

## ทดสอบ

```sh
scripts/test.sh
scripts/test.sh --filter=water
```

ตั้ง `GODOT_BIN` หากชื่อ executable ต่างจาก `godot` สคริปต์จะ import โปรเจกต์ ตรวจ error และรันเทสต์อัตโนมัติ มี CI ใน `.github/workflows/tests.yml`

เทสต์ครอบคลุมคณิตศาสตร์ hex, seed, แผนที่ 50 seed, JSON/RNG roundtrip, กฎน้ำ ประตู ระหัด และการอนุรักษ์มวลใน 100 seed × 6 เทิร์น ดูผลและขอบเขตที่ [PROGRESS](docs/PROGRESS.md)

ถ่ายภาพจากหน้าต่างที่เรนเดอร์ได้ (หรือ virtual display; ใช้ `--headless` ถ่ายภาพไม่ได้):

```sh
mkdir -p screenshots
godot --path . -- --scene=sandbox --seed=42 --lang=th --screenshot=screenshots/sandbox.png
```

เกมจะรอ 30 เฟรม บันทึก PNG แล้วออก ภาพเกมทั้งหมดสร้างจากโค้ด ฟอนต์ Noto Sans Thai แนบใบอนุญาตไว้ใน `assets/fonts/OFL.txt`
